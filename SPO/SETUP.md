# Spam Prevention Office 設定

## 起動

1. `.env` の `TOKEN` にDiscord Developer Portalで発行したBotトークンを設定します。
2. Botを各サーバーに招待し、メッセージ閲覧・削除、メンバーのBAN／キック、ログ送信に必要な権限を与えます。
3. 各サーバーでチャンネルを指定します。チャンネル名による自動検出も使えます。
4. `python run.py` で起動します。データベースは起動時に初期化・移行されます。

## チャンネル指定コマンド

サーバー管理者が、設定したいチャンネル内でなくても実行できます。

```text
!spo blacklist #チャンネル
!spo whitelist #チャンネル
!spo logs #チャンネル
```

`!spo log #チャンネル` も利用できます。設定はサーバーごとにSQLiteへ保存され、再起動後も維持されます。3つのチャンネルが揃うまでは、そのサーバーのスパム監視・制裁は行いません。

チャンネル名を `blacklist`、`whitelist`、`logs` にした場合は自動検出します。日本語名の `ブラックリスト`、`ホワイトリスト`、`ログ` や `ブラックリスト登録`、`ホワイトリスト登録`、`監査ログ`、`検知ログ` なども認識します。

## スコア

検知ポイントはサーバーとユーザーごとに累積保存されます。最後の減算基準時刻から7日経過するごとに10ポイントを差し引き、その後、そのメッセージで検出したポイントを加算します。減算後の値は0を下回りません。合計スコアが100以上になると、既存の制裁処理が実行されます。

## サーバー間の分離と既存データ

ブラックリスト、ホワイトリスト、累積スコア、ログはサーバーごとに分離します。既存のSQLiteリストは `legacy` スコープに保持し、各サーバーには自動適用しません。引き続き使う項目は各サーバーの登録チャンネルから登録し直してください。

`.env.example` を設定見本として利用できます。実トークンが共有された場合はDiscord Developer Portalで再発行してください。
